Privacy Policy

Last updated: 31 October 2026

Information you enter

The runway calculator performs its calculation in your browser. The values you enter are not submitted to a BilaForm server by this website.

Website storage and network requests

When hosted over HTTPS or localhost, the site may cache its own pages and files on your device so it can reopen offline. The page also requests fonts from Google Fonts when a network connection is available; that provider receives the normal connection information needed to deliver the font files. No analytics code or account system is included here. A static host may keep standard server request logs under its own policy.

Data protection rights and contact

Where the Kenya Data Protection Act applies, data subjects have rights including being informed about use, accessing their data, objecting to processing, and correcting or deleting misleading data. The static prototype has no user database, but a BilaForm operator should add a monitored privacy contact before collecting personal information or launching account features. See the Office of the Data Protection Commissioner guidance.

Contact

No support mailbox is configured yet. See the contact page for the current status. This prototype notice should be reviewed against the actual hosting, processing, and support arrangements before public launch.
